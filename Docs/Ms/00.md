
### **2. Facturación Automática**
```
Cada mes/año → Calcula prima → Genera factura → Espera pago → Actualiza estado
```

**Reglas de Negocio:**
- Si no paga en X días → Póliza suspendida
- Si paga después de suspensión → Reactivación automática
- Prima puede cambiar solo en renovación

### **3. Procesamiento de Claims**
```
Siniestro ocurre → Cliente reporta → Validación → Investigación → Cálculo → Pago
```

**Reglas de Negocio:**
- Solo procesar si póliza está activa en fecha del siniestro
- Indemnización = Daños - Deducible (si Daños > Deducible)
- Actualizar historial del cliente (afecta futuras primas)

## **⚡ PROCESOS CONCURRENTES**

El sistema debe manejar **múltiples procesos simultáneos**:

```
PÓLIZA ACTIVA puede estar:
├── Facturando (proceso mensual)
├── Procesando claim (evento inesperado)
├── Renovando (proceso anual)
└── Modificándose (solicitud del cliente)
```

## **🧠 LÓGICA DE DECISIONES CRÍTICAS**

### **Cálculo de Prima (Pricing)**
```
Prima = Base_Producto × Factor_Riesgo × Factor_Cliente × Factor_Mercado

Donde:
- Base_Producto: costo base del tipo de seguro
- Factor_Riesgo: edad, ubicación, historial, etc.
- Factor_Cliente: descuentos, penalizaciones
- Factor_Mercado: competencia, regulaciones
```

### **Evaluación de Claims**
```
¿Es válido el claim?
├── ¿Póliza activa en fecha siniestro? → SÍ/NO
├── ¿Evento cubierto por póliza? → SÍ/NO
├── ¿Dentro de límites de cobertura? → SÍ/NO
└── ¿Cumple deducible mínimo? → SÍ/NO
```

### **Gestión de Pagos**
```
¿Qué hacer con el pago?
├── Pago a tiempo → Mantener activa
├── Pago tardío (1-30 días) → Cargar interés
├── No pago (30+ días) → Suspender
└── No pago (60+ días) → Cancelar
```

## **🔗 RELACIONES FUNDAMENTALES**

```
CLIENTE (1) ←→ (N) PÓLIZAS
PÓLIZA (1) ←→ (N) FACTURAS
PÓLIZA (1) ←→ (N) CLAIMS
PÓLIZA (1) ←→ (N) COBERTURAS
```

## **⏰ EVENTOS TEMPORALES AUTOMÁTICOS**

El sistema debe "despertar" automáticamente para:

1. **Facturación Masiva** (1ro de cada mes)
2. **Renovaciones** (30 días antes de vencer)
3. **Recordatorios de Pago** (5 días después de vencida)
4. **Suspensiones** (30 días sin pago)
5. **Cancelaciones** (60 días sin pago)

## **🚨 REGLAS DE INTEGRIDAD**

**Nunca puede ocurrir:**
- Póliza activa sin pago del mes actual
- Claim pagado sin póliza vigente
- Modificación de póliza durante claim activo
- Prima negativa o cero
- Cobertura que exceda límites del producto

## **📊 INDICADORES CLAVE (KPIs)**

El sistema debe calcular automáticamente:
- **Ratio de Claims**: Claims pagados / Primas cobradas
- **Tiempo promedio** de resolución de claims
- **Tasa de renovación** de pólizas
- **Morosidad** por cliente/región
- **Rentabilidad** por producto
